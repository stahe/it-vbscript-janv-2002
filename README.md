# Introduzione a VBScript

Questo repository contiene il codice sorgente e la documentazione relativi al corso introduttivo su VBScript.

🔗 **[Visualizza il corso online](https://stahe.github.io/it-vbscript-janv-2002/)**

## Panoramica

VBScript è un linguaggio di scripting per Windows che può essere utilizzato in vari campi. È facile da imparare e funge da porta d'accesso a Visual Basic per Windows, da cui deriva direttamente.

Sebbene VBScript non sia un linguaggio orientato agli oggetti (il concetto di ereditarietà, ad esempio, non esiste), presenta alcune caratteristiche orientate agli oggetti. La sua potenza risiede nella capacità di utilizzare gli oggetti forniti dal proprio contenitore di esecuzione, nonché i componenti ActiveX disponibili sul computer Windows. Ciò gli consente di competere con linguaggi inizialmente più ricchi di funzionalità, come Perl, JavaScript o Python.

## Contesti di esecuzione

VBScript può essere eseguito in vari ambienti:

**Windows Scripting Host (WSH)**: Per l'uso diretto in Windows, in particolare per la scrittura di script di amministrazione di sistema. WSH è tipicamente incluso di serie nel sistema operativo Windows.



**Internet Explorer**: Utilizzato all'interno di pagine HTML, fornisce un'interattività che non può essere ottenuta con il solo HTML.


**Internet Information Server (IIS) / Personal Web Server (PWS)**: VBScript viene utilizzato per la programmazione web lato server tramite la tecnologia ASP (Active Server Pages) di Microsoft.



## Collegamento a Visual Basic e VBA

Poiché VBScript deriva da Visual Basic, funge da eccellente introduzione a questo linguaggio ampiamente utilizzato nell'ecosistema Windows. Inoltre, prepara gli utenti a **VBA (Visual Basic for Applications)**, la versione utilizzata nella suite Microsoft Office (in particolare Excel).

Pertanto, VBScript è un punto di ingresso privilegiato per lo sviluppo di applicazioni Windows.
